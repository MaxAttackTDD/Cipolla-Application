# La matrice de Cipolla

Un carnet pour situer tes actes, et ceux des autres envers toi, selon les lois fondamentales de la stupidité humaine de l'historien Carlo M. Cipolla : intelligent, naïf, bandit ou stupide.

**Ouvrir l'application :** https://maxattacktdd.github.io/Cipolla-Application/

## L'installer sur son téléphone

- **iPhone et iPad :** ouvre le lien dans Safari, touche « Partager », puis « Sur l'écran d'accueil ».
- **Android :** ouvre le lien dans Chrome, puis menu, « Ajouter à l'écran d'accueil ».

Une fois installée, l'application fonctionne même sans réseau.

## Tes données

Tout reste sur ton appareil : rien n'est envoyé à un serveur, personne d'autre ne voit tes réponses. Pense à faire « Exporter mes données » de temps en temps, dans l'onglet Progrès.

## Ce que contient l'application

- **Accueil :** ton niveau, ta série de jours, le défi du jour et les bilans à faire.
- **Évaluer :** un parcours pas à pas, avant d'agir (prévision verrouillée) ou après coup. Le verdict n'apparaît qu'à la fin, une fois les deux côtés notés.
- **Carnet :** l'historique, avec les bilans à faire.
- **Progrès :** expérience, niveaux, badges, la collection des huit profils, puis les statistiques (répartition, calibration de tes prévisions, part de chance).
- **Personnes :** noter les actes de quelqu'un envers toi, comme dans l'annexe de l'essai.
- **Comprendre :** les cinq lois, les huit profils et les limites du modèle.

Les points récompensent la méthode (demander l'avis des personnes concernées, prévoir, faire le bilan), jamais le verdict obtenu. Ils se recalculent à partir du carnet : une sauvegarde importée restaure aussi la progression.

L'essai de Cipolla est une satire : la grille est un outil de réflexion, pas une mesure scientifique.
